# Tripo Texture Fixer

A high-performance, browser-based 3D workstation designed specifically for inspecting, repainting, and fixing textures on 3D models generated by Tripo AI and other generative 3D pipelines.

Built with **React 18**, **TypeScript**, **Three.js**, **Vite**, and styled with **Park UI** (Panda CSS + Ark UI).

---

## ✨ Features

- **Dual-Synchronized Viewports**:
  - **3D WebGL Viewport**: Smooth Three.js rendering with OrbitControls, studio lighting presets, turntable auto-rotation, and unlit flat diffuse inspection.
  - **2D UV Canvas Editor**: Real-time canvas painting engine with sub-pixel resolution, zoom, and panning.
- **Interactive UV Island Mapping**:
  - Raycast clicking on the 3D model automatically detects, highlights, and masks the corresponding UV island.
  - Selecting an island in 2D highlights its exact mesh triangles in 3D in real-time.
  - Adjustable UV line thickness presets (`0.5px`, `1.0px`, `1.5px`, `2.0px`, `3.0px`) and visibility toggle (`U`).
- **Comprehensive Texture Painting Toolkit**:
  - **Brush**: Pressure-sensitive, soft-round and ink brush engines with configurable size, opacity, hardness, spacing, and smoothing.
  - **Eraser**: Clean texture erasing with alpha blending.
  - **Eyedropper**: Sample colors directly from either 2D texture or 3D surface raycasting.
  - **Bucket Fill**: Instant island boundary-aware flood filling.
  - **Clone Stamp**: Sample source textures (`Alt + Click`) to paint over seams, artifacts, or missing details.
  - **Smudge & Blur**: Blend colors, soften hard seams, and feather edges smoothly.
- **Constraint Modes**:
  - **Free Mode**: Paint freely across the entire texture sheet without boundaries.
  - **On Selection Mode**: Paint strokes are strictly clipped to the boundary of the selected UV island, preventing bleeding into adjacent islands.
- **Texture Repair & Processing**:
  - **UV Seam Margin Dilation**: Extends island perimeter pixels outwards by configurable margins (`1px` to `8px`) to eliminate white seams and mipmapping artifacts.
  - **Color Grading**: Live brightness, contrast, saturation adjustment, and color inversion.
  - **Blend Modes**: Normal, Multiply, Screen, Overlay, Soft Light, Add/Lighten, Darken, Color Dodge.
- **Export Options**:
  - Binary `.glb` with repainted textures re-embedded directly into the model via `GLTFExporter`.
  - Standalone high-resolution `.png` texture map export.
- **Park UI Dark Monochromatic Workstation**:
  - Professional, clean workstation theme with pure dark neutral palette and zero distracting colors.
  - 100% responsive top bar with smart priority collapse.

## 🚀 Quick Start

### Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ayoub-sahraoui/tripo-texture-fixer.git
   cd tripo-texture-fixer
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   ```

## 🐳 Docker Setup

Tripo Texture Fixer includes a production-ready, multi-stage Docker build served via lightweight Nginx Alpine with gzip compression and caching headers.

### Run with Docker Compose (Recommended)

```bash
docker compose up --build
```
Access the application at [http://localhost:3000](http://localhost:3000).

### Build and Run with Docker CLI

```bash
# Build the image
docker build -t tripo-texture-fixer .

# Run the container
docker run -d -p 3000:80 --name tripo-texture-fixer tripo-texture-fixer
```

## ⌨️ Keyboard Shortcuts

|---|---|
| `B` | Brush Tool |
| `E` | Eraser Tool |
